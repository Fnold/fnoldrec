Search Syntax

The FNOLDREC card search engine has a lot of expressions to filter out cards.

In addition to the standard card names and unit stats in the X/X/X/X format, you can further refine your card search in a variety of ways.

Basic expressions:

Searching cards by Type

Cards can be searched by their type:
action - Searches only Actions.
actionf - Searches only Actions with the FLASH tempo.
actiono - Searches only Actions with the ORDER tempo.
actionoc - Searches only Actions with the ORDER tempo, which have Charges.
actionp - Searches only Actions with the PLAN tempo.
actiont - Searches only Actions with the TRAP tempo.
actionx - Searches only Actions without a tempo.
unit - Searches only Units.
unitn - Searches only Units, which can't be Operators.
operator - Searches only Units, which can be Operators.
operators - Searches only Operators with a star.
operatorns - Searches only Operators without a star.
operatorg - Searches only Units, which are Grays.
operatorng - Searches only Operators, which aren't Grays.
devotion - Searches only cards with the Devotion mechanic.
domain - Searches only cards with the Domain mechanic.
bid - Searches only cards with the Bidding mechanic.
attaint - Searches only cards with the Attaint mechanic.
revive - Searches only cards with the Revive mechanic.
infamy - Searches only cards with the Infamy mechanic.
clash - Searches only cards with the Clash mechanic.

Example: unit Searches only Units.

Searching cards by Color

Units can be searched by their color combination:
r--- - Searches only red Units.
rbyg - Searches only Units with all colors.
r--g - Searches only red-green Units.
--y- - Searches only yellow Units.
r-yg - Searches only red-yellow-green Units.

Example: r-y- Searches only Units with the red-yellow color combination.

Searching cards by Group

Each card is in a group. Groups are only used for categorization and do not resemble the update the card was added in or serve any gameplay benefits.

Group List CMF - Canteen Mischief
FDR - FNOLDRENALINE
FRC - FNOLDREC
HAL - Hal1
PRM - Promo System
SEA - Sold Sea

Example: fdr Searches only cards in the FNOLDRENALINE group.

Searching cards by Update

Cards can be searched by the update they were added in:
v1 - Searches only cards added in the V1 version. (2026).

Example: v1 Searches only cards added in the V1 version. (2026).

Searching cards by Artist

Cards can be searched by the artist who drew the art:

Artist List Fnold
Krafcik
Maksiuu

Example: fnold Searches only cards illustrated by the artist Fnold.
